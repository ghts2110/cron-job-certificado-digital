Objective: Launch an MVP within 3 months
Focus: Help accountants in their work

**Why it exists?**
Because in nowadays accountants do a lot of work that can be automatized and simplified using [[APIs]] from the govern to help in their day-a-day jobs.

**What will be delivered?**
An web application that has the focus to be an assistant, to make some works easier and to help in the integration, keeping the accountant updated to new jobs and needs.

**Who will be evolved?**
Accountants
